# React Color Picker

A simple React application that allows users to select a color using the native HTML color picker and instantly preview the selected color on the screen

## Preview

When a user chooses a color:

    - The backgound of the preview box updates in real time.
    - The selected HEX color code is displayed.
    - Changes are managed using React''s useState hook.

## Features

- Interactive color picker
- Real-time color preview
- Displays selected HEX color value
- Built with React Hooks ( useState )
- Simple and Responsive design
